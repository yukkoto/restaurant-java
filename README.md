# Ресторан — контрольная работа № 1

Консольная информационная система на Java 17+ и PostgreSQL. Управляет клиентами и заказами ресторана. Данные сохраняются в базе и остаются после закрытия программы.

**Начните с [инструкции по запуску](docs/01_START.md).** Затем прочитайте [объяснение кода](docs/02_EXPLANATION.md) и [сценарий защиты](docs/03_DEFENSE.md).

## Как устроена система

`ConsoleUi → Service → Repository / JDBC → PostgreSQL`

Две сущности: **Customer** (клиент) и **RestaurantOrder** (заказ). Один клиент может иметь несколько заказов. Заказ всегда принадлежит одному существующему клиенту.

Чтобы сохранить простоту, состав заказа вводится текстом, например «Пицца, чай», а сумма — вручную. Каталог блюд, автоматический расчёт стоимости, авторизация и бронирование столов не входят в эту версию. У одного стола может быть несколько заказов. Дата создания назначается автоматически; часовой пояс не хранится. Приложение рассчитано на одного оператора и учебный объём данных. Поиск, фильтры и статистика читают записи из БД в коллекции Java; полноценная синхронизация нескольких одновременно работающих операторов не реализована.

## Возможности

- Создание, просмотр, изменение и удаление клиентов и заказов.
- Получение записи по ID и изменение статуса заказа.
- Поиск по составу заказа и имени клиента без учёта регистра.
- Фильтры по статусу, столу и диапазону дат включительно.
- Сортировка по сумме и дате по возрастанию.
- Восемь показателей статистики.
- Экспорт двух таблиц в настоящий `.xlsx`.
- Вывод имён таблиц базы и их содержимого.
- Обработка неправильного ввода, отсутствующих записей и ошибок базы.

## Быстрый запуск после настройки базы

Из папки проекта:

```shell
java -jar restaurant.jar
```

Для пересборки изменённого исходного кода:

```shell
mvn clean package
java -jar target/restaurant-1.0.jar
```

Условие команды: 4 участника. Заполните реальные ФИО и группу в `docs/TEAM.md`, самостоятельно отметьте вариант в таблице преподавателя. Ссылка на эту таблицу в присланном задании отсутствует.
