# Запуск с нуля

## 1. Что понадобится

1. **JDK 17 или новее** — для запуска и разработки Java-программ. Подойдёт JDK 17 или 21: [Eclipse Temurin](https://adoptium.net/temurin/releases/).
2. **IntelliJ IDEA** с поддержкой Java — для открытия и изменения проекта: [официальная загрузка](https://www.jetbrains.com/idea/download/).
3. **PostgreSQL и pgAdmin** — сервер базы данных и окно управления им: [официальная загрузка PostgreSQL](https://www.postgresql.org/download/). Для Windows установщик обычно предлагает оба компонента. На macOS можно установить сервер PostgreSQL и pgAdmin отдельно.

Сначала распакуйте архив целиком. Работайте с папкой `restaurant`, внутри которой лежит `pom.xml`.

При установке PostgreSQL запомните пароль пользователя `postgres`. Обычно сервер работает на порту **5432**. pgAdmin — только программа управления: сам сервер PostgreSQL тоже должен быть запущен.

Если PostgreSQL уже установлен, повторная установка не нужна. Если ваш пользователь называется иначе, используйте его имя вместо `postgres` во всех настройках.

## 2. Создать базу

1. Откройте pgAdmin и подключитесь к своему серверу, введя пароль PostgreSQL.
2. Слева раскройте сервер. Нажмите правой кнопкой на **Databases → Create → Database**.
3. Введите имя `restaurant`, владелец — ваш пользователь (обычно `postgres`). Нажмите **Save**.
4. Выберите созданную базу **restaurant**, затем **Tools → Query Tool**.
5. Откройте в Query Tool файл `sql/01_schema.sql`, выполните весь текст кнопкой запуска (обычно F5). Будут созданы две таблицы.
6. В том же окне, оставаясь в базе **restaurant**, откройте `sql/02_seed.sql` и выполните его **один раз**. Появятся 5 клиентов и 10 заказов.

Файл `sql/00_create_database.sql` — альтернативный способ создания базы через SQL. Его запускают отдельно, подключившись к служебной базе `postgres`. Если вы уже создали `restaurant` кнопкой Create, этот файл запускать не нужно.

**Не выполняйте скрипт начальных данных при каждом запуске.** Он нужен только для первого заполнения. При повторном запуске будет ошибка уникального телефона; данные не удвоятся. Если pgAdmin после ошибки показывает незавершённую транзакцию, выполните `ROLLBACK;`.

Проверка через Query Tool:

```sql
SELECT * FROM customers ORDER BY id;
SELECT * FROM restaurant_orders ORDER BY id;
```

У вас должно быть 5 строк в первой таблице и 10 во второй.

## 3. Указать подключение

Откройте файл `db.properties` в корне проекта:

```properties
url=jdbc:postgresql://localhost:5432/restaurant?connectTimeout=5&socketTimeout=10
user=postgres
password=CHANGE_ME
```

Замените `CHANGE_ME` на пароль, который вы задали при установке PostgreSQL. Например, если ваш пароль `myPassword123`, последняя строка будет `password=myPassword123`. Кавычки не нужны. Не публикуйте файл с настоящим паролем.

Что значит адрес:

- `localhost` — база находится на этом компьютере;
- `5432` — порт PostgreSQL, измените его, если при установке выбрали другой;
- `restaurant` — имя созданной базы;
- параметры Timeout ограничивают ожидание ответа.

В `.properties` обратную косую черту в пароле пишут дважды: `\`. Обычно достаточно просто вставить пароль без кавычек. Имя базы, имя пользователя и пароль — это три разные вещи.

Можно хранить личные настройки в `db.local.properties` и запускать так:

```shell
java -jar restaurant.jar db.local.properties
```

Этот файл исключён из Git через `.gitignore`.

## 4. Самый быстрый запуск готовой программы

Откройте терминал **в папке restaurant**. В Windows можно открыть папку в Проводнике, нажать на адресную строку, написать `cmd` и нажать Enter.

Проверьте наличие Java:

```shell
java -version
```

Нужна версия 17 или новее. Затем:

```shell
java -jar restaurant.jar
```

Вы увидите меню ресторана. Вводите номер и нажимайте Enter. После операции программа возвращается в меню. В подменю `0` возвращает назад; в главном меню `0` завершает программу.

Если в консоли Windows вместо русских букв непонятные символы, перед запуском выполните:

```bat
chcp 65001
java -Dfile.encoding=UTF-8 -jar restaurant.jar
```

В Windows Terminal и консоли IntelliJ обычно удобнее работать с UTF-8.

## 5. Открыть исходный код в IntelliJ IDEA

1. Выберите **Open** и откройте папку `restaurant` либо её `pom.xml` как проект Maven.
2. Дождитесь, пока Maven загрузит библиотеки. При первом открытии нужен интернет.
3. В **File → Project Structure → Project SDK** выберите JDK 17 или новее. Если JDK нет, воспользуйтесь **Download JDK**.
4. Откройте `src/main/java/ru/mirea/restaurant/Main.java`.
5. Нажмите зелёный треугольник рядом с `main` и выберите **Run Main.main()**.
6. В конфигурации запуска рабочая папка (**Working directory**) должна быть папкой `restaurant`, где лежит `db.properties`. Для русских букв установите кодировку консоли UTF-8 при необходимости.

Вручную скачивать JDBC и Apache POI не нужно — Maven возьмёт их из `pom.xml`. Отдельный Maven для запуска через IDEA обычно не требуется: IDE умеет использовать встроенный Maven.

После изменения исходного кода запускайте `Main` из IDEA. Старый `restaurant.jar` сам по себе не обновляется.

## 6. Собрать новый JAR

В IntelliJ откройте боковую панель **Maven → Lifecycle → package** и запустите `package`. Либо установите Maven и из папки проекта выполните:

```shell
mvn clean package
```

Новый файл: `target/restaurant-1.0.jar`. Это JAR со всеми нужными библиотеками. Его запускают так:

```shell
java -jar target/restaurant-1.0.jar
```

Файл `original-restaurant-1.0.jar`, если появился, для обычного запуска не нужен.

## 7. Экспорт в Excel

В главном меню выберите **7**. Программа прочитает клиентов и заказы из PostgreSQL и сохранит файл в `exports/restaurant_ДАТА_ВРЕМЯ.xlsx`. Полный путь появится в консоли. Откройте файл в Excel или LibreOffice Calc.

Листы «Заказы» и «Клиенты» связаны столбцом «ID клиента». Суммы и даты записаны как числа и даты Excel, телефон — как текст. Это снимок данных на момент выгрузки; изменения в Excel не импортируются назад в базу.

Готовый пример на начальных данных есть в `examples/restaurant.xlsx`.

## 8. Если что-то не работает

| Сообщение / ситуация | Что проверить |
|---|---|
| `java` не найдена | Установите JDK и откройте терминал заново. Или запускайте через IDEA с выбранным JDK. |
| `UnsupportedClassVersionError` | Нужна Java 17+, проверьте `java -version`. |
| Нет `db.properties` | Запускайте из папки проекта. Или передайте путь: `java -jar restaurant.jar "путь/к/db.properties"`. |
| Не удалось подключиться к БД | Запущен ли сервер PostgreSQL? Верны ли порт, база, пользователь и пароль? |
| Ошибка SQL, таблица не найдена | Выполните `01_schema.sql` именно в той базе, которая указана в настройках. |
| Таблицы пустые | Выполните `02_seed.sql` один раз после создания пустых таблиц. |
| Телефон уже существует | У клиента должен быть уникальный телефон. Формат строго `+7` и ещё 10 цифр. |
| Нет записи с таким ID | Сначала выведите список. После удаления ID могут иметь пропуски — это нормально. |
| Нельзя изменить заказ | Данные меняются только в статусе «Новый». Статус меняется отдельным пунктом. |
| Excel не сохранился | Проверьте права записи и свободное место. |
| IDEA не видит библиотеки | В Maven нажмите Reload All Maven Projects, проверьте интернет. |

При ошибке подключения программа остаётся в меню: исправьте настройки сервера и повторите действие. Если изменили сам файл `db.properties`, перезапустите программу — он читается при запуске.
