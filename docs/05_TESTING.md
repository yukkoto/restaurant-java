## Как повторить тесты

Для обычной работы приложения этот раздел не нужен.

1. Создайте отдельную базу с именем **restaurant_test**.
2. Создайте файл `test-db.properties`, аналогичный `db.properties`, но с базой `restaurant_test` в URL и своими логином/паролем.
3. Передайте абсолютный путь к нему через переменную окружения `RESTAURANT_TEST_CONFIG`.
4. Из папки проекта выполните `mvn test`.

**Тесты очищают таблицы своей базы перед каждым тестом.** Не используйте базу с важными данными. Дополнительная проверка в тестах разрешает очистку только при имени базы `restaurant_test`.

Windows PowerShell:

```powershell
$env:RESTAURANT_TEST_CONFIG = "C:\полный\путь\test-db.properties"
mvn test
```

macOS / Linux:

```shell
RESTAURANT_TEST_CONFIG="/полный/путь/test-db.properties" mvn test
```

Без этой переменной интеграционные тесты **пропускаются**, а не считаются успешно выполненными. Это позволяет собрать приложение без тестового сервера. Результаты Maven находятся в `target/surefire-reports`.
