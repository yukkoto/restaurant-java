# Соответствие заданию

| Требование | Где реализовано |
|---|---|
| Консольное меню, повторение операций | `ui/ConsoleUi.java`, циклы while в меню |
| Предметная область «Ресторан» | Клиент, заказ, стол, состав, сумма, ресторанные статусы |
| Минимум две связанные сущности | `Customer`, `RestaurantOrder`, внешний ключ customer_id |
| CRUD основной сущности | `OrderService` и `OrderRepository`, меню «Заказы» |
| CRUD участника системы | `CustomerService` и `CustomerRepository`, меню «Клиенты» |
| Минимум один enum | `OrderStatus`, пять значений |
| Минимум пять бизнес-правил | 11 правил перечислены в `02_EXPLANATION.md`, реализованы в сервисах |
| Два поиска | По составу заказа, по имени клиента |
| Два фильтра | Три: статус, стол, диапазон дат |
| Две сортировки | Сумма, дата, обе по возрастанию |
| Минимум пять показателей | 8: клиенты, заказы, пять счётчиков статусов, выручка |
| Excel .xlsx из базы | `ReportService`, `ExcelExporter`, пункт 7 |
| Вывод таблиц БД | Пункт 8: список названий и содержимое двух таблиц |
| Классы, поля private, конструкторы, методы | Модели, сервисы и репозитории |
| Интерфейс и полиморфизм | `CrudRepository<T>`, две реализации, использование интерфейса в сервисах |
| Коллекции | ArrayList, HashSet, LinkedHashMap; List, Set, Map |
| Собственные исключения | BusinessException, EntityNotFoundException, DataAccessException |
| JDBC и безопасные параметры | Connection, PreparedStatement, ResultSet, try-with-resources |
| SQL отдельно от UI | SQL находится в repository, не в ConsoleUi |
| PostgreSQL | Настройки db.properties, драйвер в pom.xml |
| PK, FK, NOT NULL, UNIQUE, CHECK | `sql/01_schema.sql` |
| 5 участников предметной области, 10 записей, ≥3 статусов | `sql/02_seed.sql`: 5 клиентов, 10 заказов, 5 статусов |
| Исходники, pom.xml, SQL, ER, Excel, инструкция | Включены в проект |
| Рабочее приложение | Собранный restaurant.jar; исходники для пересборки |
| База для последующих работ | Сервисы и репозитории отделены от UI, можно подключить JavaFX / REST |
| Команда из четырёх человек | Шаблон TEAM.md; реальную регистрацию выполняют участники |

CSV в задании необязателен, поэтому реализован обязательный Excel. Отдельная таблица блюд также не требуется общим текстом задания и не добавлена для сохранения простоты.
